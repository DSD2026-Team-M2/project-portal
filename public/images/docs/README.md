Place documentation images here when they need to be embedded in markdown articles.

Recommended use:

- use case diagram exports
- architecture diagrams
- annotated workflow screenshots

For the Software Requirements Specification, a stable filename like this works well:

- `images/docs/use-case-diagram-v1.png`

Example markdown:

```md
![Use Case Diagram](images/docs/use-case-diagram-v1.png)
```
