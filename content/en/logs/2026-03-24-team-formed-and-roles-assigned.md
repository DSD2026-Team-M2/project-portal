## The Team

- Lee (Lee-YihangLI-55230714)
- Kika (Vasconcelos Francisca)

## Initial Role Assignment

The initial working structure of M2 is as follows:

- Lee - Project Manager  
  Responsible for task allocation, overall progress, cadence control, requirement alignment, and external communication.

- Hai - System Architect and Designer  
  Responsible for page design, requirement analysis, and user research.

- BFD_QT - Web Maintainer  
  Responsible for developing and maintaining the team website, and for documenting the development process and progress of the project.

- Kika - Vice PM / Programmer  
  Works asynchronously from Portugal, coordinates with the PM, and implements user interface logic for static rehabilitation data and historical records.

- Shu - Programmer  
  Responsible for implementing and displaying 3D reconstruction based on sensor-collected data.

## From Group to Working Team

With both members and roles now in place, M2 stopped being only a list of names and became a team able to collaborate around the Clinical Web Dashboard direction in a more concrete and deliverable way.
