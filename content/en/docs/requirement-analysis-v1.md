## Scope

Define the role, boundaries and minimum page structure of the project portal.

## Must Answer

- What is the overall project?
- What is the portal for?
- What is M2 responsible for?
- Where are logs, milestones, documents and deliverables located?

## Constraints

- The portal must not impersonate the main product web application.
- The implementation should stay simple enough for a Vite, React and TypeScript learner to maintain.
- Content updates should rely on markdown and generated indexes wherever possible.
